# 日本精品生活馆

白色简约风格的电商框架，面向日本生活用品选品场景，按 **Cloudflare 免费优先** 的方向组织。代码使用 nfsc 公司账号的仓库：[nfscdaiwa-create/japan-life-store](https://github.com/nfscdaiwa-create/japan-life-store)。

**当前已完成可操作的结构预览，尚未上线营业。** 商品、AI 生成示意图与价格均为演示资料；没有真实订单、付款或客户资料收集。“日本精品生活馆”目前是项目名称，正式品牌、经营主体和交易政策尚未确定。

## 已有页面与交互

| 页面 | 当前可体验内容 |
| --- | --- |
| 首页 `/` | 五组可展开的选物目录、键盘切换、商品入口、六件选品示例与材质细节 |
| 商品目录 `/catalog/` | 分类、关键词搜索、价格区间、价格／名称排序、本机收藏 |
| 商品详情 `/products/:slug/` | 6 件示例商品，图片、物件资料、展示颜色、数量与加入示例购物袋 |
| 示例购物袋 `/cart/` | 按商品与展示颜色分行、本地保存、数量修改、移除、演示金额计算；结算关闭 |
| 关于 `/about/` | 选品理念、项目筹备状态与产地说明 |
| 购物说明 `/guide/` | 当前预览范围、配送／售后待配置状态、本地数据清除 |
| 中文后台 `/admin/` | 9 个只读结构模块，没有真实后台身份或管理写入 |
| 404 页面 | 不存在的地址显示明确的返回入口 |

共构建 **13 个静态页面**。后台模块为：概览、商品管理、分类管理、库存管理、订单管理、商品素材、配送与售后、用量与提醒、店铺设置。

当前界面为简体中文；繁体中文、日文与英文属于后续结构规划，**尚未实现翻译或语言切换**。演示币种为 JPY 日元，不代表已确定的实际结算币种。

## 本地运行

需要 **Node.js 24 或以上**。构建、检查、测试及本地预览使用 Node 内置能力，无第三方运行时依赖，无需先安装前端框架。

```sh
npm run verify
npm run dev -- --host 127.0.0.1 --port 3000
```

浏览器打开 `http://127.0.0.1:3000/`；中文后台为 `http://127.0.0.1:3000/admin/`。

| 命令 | 用途 |
| --- | --- |
| `npm run build` | 将页面与资源生成到 `dist/` |
| `npm run check` | 检查构建产物、页面链接与资源等基本完整性 |
| `npm test` | 运行购物袋、筛选、后端与数据约束测试 |
| `npm run verify` | 顺序执行构建、检查和测试 |
| `npm run dev` | 预览已有 `dist/`，默认端口 3000 |

本地预览不自动重新构建。修改源文件后运行 `npm run build`，再刷新页面。测试通过不等于已经完成远程 Cloudflare 部署或真实支付验收。

## 当前边界

- 正式商品目录与演示目录相互独立，示例数据不得导入生产数据库。
- 已有 Worker API 和 D1 初始迁移，**远程 D1、R2 尚未创建或绑定**。
- 结算与管理接口始终返回明确的未配置状态，不接受付款、创建订单或开放管理操作。
- 用量面板显示“未连接／未配置”；没有实际的用量采集、提醒任务或提前告警。
- 当前所有页面保留 `noindex`。这只是搜索引擎收录提示，不是登录保护。
- 真实商品、品牌名称、经营主体、客服、销售地区、配送费、税费与售后规则，需依据后续取得的实际资料完善。

## 当前界面版本

首页使用白底、黑色目录分栏和以使用动作为主题的图片。`public/assets/edition.css` 负责店铺视觉，`public/assets/chapter.js` 负责五组目录的单项展开；没有添加前端框架或第三方运行时依赖。

首页手机端将竖向目录转为五个横向入口；商品列表使用同一套五字分类，手机分类以六格完整显示。分类菜单提供收藏、关于与购物说明入口，价格区间可以展开筛选。支持键盘操作与减少动态效果的系统偏好。图片和商品均保持示意标识，当前不是正式商品销售页面。

商品详情将颜色、数量和加购操作集中呈现；购物袋按展示颜色分别保存。浏览器返回、跨标签页更新与收藏取消后的焦点均有对应处理。

验证范围见 [界面验收记录](docs/ui-review.md)。
