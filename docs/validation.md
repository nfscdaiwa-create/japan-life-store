# 首版框架验证记录

日期：2026-11-04。验证对象为当前结构预览，不代表真实开店验收。

## 自动检查

- `npm run verify`：构建 13 页，检查 494 个本地链接与资源，15 项测试通过，0 失败、0 跳过。
- `node --check`：浏览器交互、本地预览服务器与 Worker 语法通过。
- SVG：7 张商品／场景插画通过 XML 解析，另有网站图标。
- 数据库迁移由 Node 24 内置 SQLite 实际执行；商品查询、草稿隔离、库存约束、整数金额、支付事件幂等和订单快照接受了测试。

## 浏览器检查

使用当前云端 Chrome 进行实际页面操作：

| 流程 | 结果 |
| --- | --- |
| 首页展示 | 白色主背景、紧凑主题区、五分类、商品卡片可见 |
| 搜索“毛巾” | 返回对应示例商品，能进入详情 |
| 详情数量改为 2 并加入购物车 | 页面切换后仍保存，显示 2 件 × 1,800 日元 = 3,600 日元 |
| 结算状态 | 按钮禁用并明确解释未开放购买 |
| 窄屏布局 | 通过同源 iframe 分别检查 390px、320px 宽度；含滚动条的内容宽度为 375px、305px，均无横向页面溢出 |
| 窄屏分类与排序 | 打开菜单，进入餐厨分类，按价格升序排列为 2,200 日元餐碗、2,800 日元杯碟 |
| 后台无效 hash | `#\_\_proto\_\_` 不再导致初始化失败；导航可进入用量页面 |
| 后台用量 | 所有未接入的账户数据保持“未连接／未配置”，未显示虚假百分比 |

窄屏检查是桌面 Chrome 中的真实 iframe 响应式布局检查，不等于已测试实体手机、移动 Safari 或所有浏览器。

## 审查修复

- 后台模块和场景参数使用自有属性白名单，避免 URL 指向对象原型属性造成崩溃或异常标题。
- 修复本地静态根目录末尾分隔符导致的路径判断错误。
- 修复窄屏标题出现单字换行，缩小桌面横幅占用，并提高后台辅助文字对比度。
