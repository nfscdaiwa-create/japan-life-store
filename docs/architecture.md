# 框架与数据边界

## 1. 本阶段目标

先确定清晰、轻量的商品浏览结构，验证白色简约风格在首页、商品列表、详情、购物车和中文后台中的一致性。演示交互可以使用，经营数据与支付能力尚未接入。

五大商品分类为餐厨器具、家居日用、美妆个护、食品茶饮、服饰配件；餐桌日常、舒适居家、午后时光和随身好物作为独立场景筛选，不重复增加一级分类。

## 2. 运行结构

| 层 | 当前职责 | 后续接入边界 |
| --- | --- | --- |
| 静态页面与资源 | 构建时生成 13 页；浏览器直接获取 HTML、CSS、JS 和 SVG | 正式商品信息需要另行实现发布与更新流程 |
| 浏览器交互 | 示例目录搜索、筛选、排序、收藏与购物车 | 不能作为真实计价或库存判断的权威来源 |
| Worker API | 商品只读接口、健康状态、统一错误响应 | 交易、后台写入和身份验证保持关闭 |
| D1 | 已编写表结构及商品读取逻辑 | 尚未创建远程数据库、执行远程迁移或录入商品 |
| R2 | 预留 `MEDIA` 绑定与商品图片对象键 | 尚未创建存储桶、实现上传或开放图片读取接口 |

`wrangler.jsonc` 的 `assets.run_worker_first` 匹配 `/api` 与 `/api/*`。普通静态页面与资源优先由 Cloudflare Static Assets 提供，API 请求由 Worker 处理；未知 API 返回 JSON 404，不伪装成成功加载的首页。

该安排减少普通浏览对动态计算的依赖。参照 [Cloudflare 静态资源路由与绑定](https://developers.cloudflare.com/workers/static-assets/binding/)；实际资源配置见 [Cloudflare 说明](cloudflare.md)。

## 3. 演示目录与真实目录分开

`src/catalog.mjs` 仅服务于结构预览。页面中的商品、价格、图片和详情均明确标识为示例；商品插画不代表实拍、供货或实际制造地。

浏览器购物车只在本机存储已知商品标识和数量，演示金额从固定目录计算。清空本地数据不会影响真实订单，因为本阶段没有订单提交功能。正式商品 API 不读取或回退到演示目录；缺少数据库时返回“正式商品目录尚未接入”。

真实交易接入时，服务器必须重新验证商品、规格、价格、库存、配送与税费，不能相信浏览器传来的总额。订单创建、库存预留、支付回调与售后流程须单独实现并验收。

## 4. 九张业务表

| 表 | 保存内容 |
| --- | --- |
| `categories` | 分类、层级、排序与开放状态 |
| `products` | 商品资料、分类、状态、币种、制造地与采购地 |
| `product_variants` | 规格、唯一 SKU、整数价格与属性 |
| `product_images` | 图片对象键、替代文字、尺寸与顺序 |
| `inventory` | 按规格管理实存、预留与补货阈值 |
| `orders` | 订单标识、金额、状态与结算幂等键 |
| `order_items` | 成交时商品名、规格、SKU、数量及单价快照 |
| `payment_events` | 支付方事件标识、签名验证时间与处理状态 |
| `settings` | 公开或内部的业务设置，不保存密钥 |

制造地 `origin_country` 与采购地 `sourcing_country` 独立，未经验证允许为空。“日本选品”或“日本采购”不能自动转成“日本制造”。

价格使用整数最小货币单位，并保留 `currency` 和 `currency_minor_unit`。当前 JPY 的最小单位指数为 0，`2800` 就是 2,800 日元，不能统一除以 100。未来接入其他币种时，前台格式化与服务端计价都需按币种处理。

库存不能为负，预留量不能超过实存量；订单明细保留成交快照，支付事件使用来源与事件 ID 的复合唯一约束。完整字段、接口参数和测试边界见 [后端说明](backend.md)。

## 5. 管理、交易与监控

中文后台是公开内容范围内的只读界面示例，不包含真实客户、订单或账户数据。真实管理 API 在身份验证未接入前全部关闭，不能以隐藏按钮或未经验证的请求头充当认证。

`POST /api/checkout` 返回未配置状态，不读取结算请求体、不创建订单、不收款。健康接口的绑定状态仅表示检测到绑定，不代表已验证远程可用性或营业条件。

用量模块保留 Workers、D1、R2 的位置和未知状态，没有实时数据，也没有已经启用的提醒。实际账户用量、通知接收地址、阈值及通知能力需在 Cloudflare 配置后再显示。

## 6. 语言与品牌

首版只有简体中文界面。后续计划将界面文案、商品翻译、金额格式与地区政策分别管理，为繁中、日文和英文预留扩展方向；目前没有翻译字典、自动翻译或语言切换功能。

“日本精品生活馆”是当前项目名。正式品牌、经营主体、域名和交易政策尚未确定；后续按照真实业务资料完善，不能由演示页面中的名称或示例金额推导已经营业。
