## 本轮采用：五物所 / WUWUSUO / wuwusuo.com

从当前网站的“器、布、净、茶、行”五个日常场景出发，采用五物所作为本轮品牌方向。三个中文字短而具体，“五”能解释已经建立的分类结构；完整拼音 `WU-WU-SUO` 共 7 个字母，没有连字符或数字。口述时需要说明“五个的五、物件的物、场所的所”，避免听成“无物所”或漏写一次 wu。

“五”应解释为五种日常场景，不是只卖五件商品，也不赋予未经证实的日本传统典故。器物、织物、洗护、茶食和随身用品各自可以持续扩展。

品牌层级：主名称“五物所”；拼音字标“WUWUSUO”；副说明“日常选物”；分类保持“器／布／净／茶／行”。本轮按此更新站内展示，实际完成范围以代码和最终页面验收为准。品牌采用不等于商标可用性已经核实，经营主体及交易政策仍待真实资料补齐。

对外目标主地址为 `https://wuwusuo.com`。仓库、Wrangler 配置及 API 健康检查使用的 `japan-life-store` 是技术项目标识，可以继续保留；不能因品牌改名就推定需要再建一个站点。
