## 建议：五物所 / WUWUSUO / wuwusuo.com

从当前网站的“器、布、净、茶、行”五个日常场景出发，建议把五物所列为第一候选。三个中文字短而具体，“五”能解释已经建立的分类结构；完整拼音 `WU-WU-SUO` 共 7 个字母，没有连字符或数字。口述时需要说明“五个的五、物件的物、场所的所”，避免听成“无物所”或漏写一次 wu。

“五”应解释为五种日常场景，不是只卖五件商品，也不赋予未经证实的日本传统典故。器物、织物、洗护、茶食和随身用品各自可以持续扩展。

建议品牌层级：主名称“五物所”；拼音字标“WUWUSUO”；副说明“日常选物”；分类保持“器／布／净／茶／行”。这是可供确认的方案，当前网站仍保留原项目名。

## 域名与正式发布的衔接

建议先确定一个中文品牌和对应的 .com 主域名。按当前页面显示的年费，优先使用单个主域名，不需要为了筹备预览一次购买多个后缀。
